# Example documents for the CI end-to-end check

A fixed set of documents, one per file type local-rag supports. Each file
is about a **different topic with distinctive vocabulary**, so the smoke
test (`scripts/smoke_test.py`) can ask one question per file and check the
right file comes back.

| File | Type | Topic | Question that should retrieve it |
| --- | --- | --- | --- |
| `beekeeping-guide.md` | Markdown | Beekeeping: hive inspection, the smoker | How do I inspect a beehive and what does the smoker do? |
| `orbital-mechanics-notes.txt` | Plain text | Orbital mechanics: Hohmann transfer, delta-v | What is a Hohmann transfer and how much delta-v does it need? |
| `library-catalogue.py` | Code | Library catalogue: find by ISBN, overdue fines | How does the library catalogue find a book by ISBN? |
| `sourdough-guide.pdf` | PDF | Sourdough: starter, levain, autolyse | How do I maintain a sourdough starter and what is autolyse? |
| `telescope-report.docx` | Word | Telescope report: Andromeda nebula, aperture | What did the telescope observation report say about the Andromeda nebula? |
| `train-timetable.html` | HTML | Train timetable: InterCity sleeper, platform 7 | When does the InterCity sleeper service depart and from which platform? |
| `birdwatching-sightings.csv` | CSV | Birdwatching: goldfinch count at the reservoir | What is the goldfinch count at the reservoir? |
| `recipes.json` | JSON | Recipes: lemon drizzle cake | What are the ingredients and baking time for the lemon drizzle cake? |
| `zebra-crossing-sign.png` | Image | OCR: zebra crossing sign text | What does the zebra crossing sign say? |
| `tone-sample.wav` | Audio | 3s tone — transcription pipeline only | — (no spoken words; only asserts the file is indexed) |
| `test-pattern-clip.mp4` | Video | 3s test pattern with tone — transcription pipeline only | — (no spoken words; only asserts the file is indexed) |

`questions.json` is the machine-readable version of this table; it lives
in `scripts/smoke_questions.json` (not here — it is test configuration, and
if it sat in this folder the service would index the questions themselves
and a search would return the question text instead of the document that
answers it). The smoke test reads it, so adding a file here and a row
there adds a check.

## Regenerating

All files (including the binaries) are generated by
`scripts/generate_examples.py` — run it from the repo root to rebuild
them from scratch. The audio/video examples are a tone and a test pattern
because there is no speech synthesis on a CI runner; they exercise the
transcription pipeline, not retrieval of spoken words.
